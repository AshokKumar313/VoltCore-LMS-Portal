## 3. Register Level Architecture & Bit Manipulation
Direct peripheral control on STM32 microcontrollers requires mastering memory-mapped I/O registers. The table below outlines the primary configuration registers used in this module:

| Register Mnemonic | Base Offset | Access | Hardware Function |
| :--- | :--- | :--- | :--- |
| **`FLASH_KEYR`** | `+0x00` | R/W | Primary configuration & control word |
| **`FLASH_CR`** | `+0x04` | R/W | High-speed data latch / status register |
| **`FLASH_SR`** | `+0x08` | R/W | Peripheral interrupt flag / clear register |

## 4. Production-Grade Bare-Metal Implementation (C99 / CMSIS)
Below is the production-ready C firmware template implementing the core logic for this module without proprietary vendor abstractions:

```c
#include <stdint.h>

// Peripheral Base Definitions
#define PERIPH_BASE       (0x40000000UL)
#define AHB1PERIPH_BASE   (PERIPH_BASE + 0x00020000UL)
#define RCC_BASE          (AHB1PERIPH_BASE + 0x3800UL)
#define GPIOA_BASE        (AHB1PERIPH_BASE + 0x0000UL)

// Register Access Pointers
#define RCC_AHB1ENR       (*(volatile uint32_t *)(RCC_BASE + 0x30UL))
#define GPIOA_MODER       (*(volatile uint32_t *)(GPIOA_BASE + 0x00UL))
#define GPIOA_BSRR        (*(volatile uint32_t *)(GPIOA_BASE + 0x18UL))

void Module20_Init(void) {
    // 1. Enable Peripheral Clock Gate
    RCC_AHB1ENR |= (1UL << 0); // Enable GPIOA clock

    // 2. Configure Register Parameters
    GPIOA_MODER &= ~(3UL << (5 * 2));
    GPIOA_MODER |= (1UL << (5 * 2)); // Pin PA5 as Output Mode
}

void Module20_Execute(void) {
    // Atomic bit manipulation (Zero race conditions)
    GPIOA_BSRR = (1UL << 5);         // Set PA5 High
    for (volatile int i = 0; i < 100000; i++);
    GPIOA_BSRR = (1UL << (5 + 16));   // Set PA5 Low
    for (volatile int i = 0; i < 100000; i++);
}

int main(void) {
    Module20_Init();
    while (1) {
        Module20_Execute();
    }
    return 0;
}
```

## 5. Hardware-in-the-Loop Verification Protocol
To verify proper silicon operation on your test bench:
1. Connect your **Nucleo-F401RE** via USB ST-LINK interface.
2. Verify target power rail stability (3.3V +/- 5%).
3. Connect logic analyzer or oscilloscope probe to designated GPIO/bus pins.
4. Flash the compiled binary using OpenOCD / GDB:
   ```bash
   arm-none-eabi-gcc -mcpu=cortex-m4 -mthumb -O2 -c module20.c -o module20.o
   openocd -f interface/stlink.cfg -f target/stm32f4x.cfg -c "program module20.elf verify reset exit"
   ```
