## I. Four-Variable Karnaugh Map (K-Map) Minimization & Glitch Elimination

In high-speed digital RTL synthesis targeting FPGAs and ASICs, Boolean simplification directly controls propagation delay and lookup table (LUT) utilization. For a 4-variable Boolean function $F(A,B,C,D)$, canonical minterms are mapped onto a two-dimensional grid arranged in reflective Gray code sequence $(00, 01, 11, 10)$:


```latex
Cell Index = 8A + 4B + 2C + D
```


Adjacent cells differ by exactly one binary literal. Groups of $2^k$ adjacent ones (pairs, quads, octets) eliminate $k$ variables, producing prime implicants.

### Mathematical Derivation of Consensus Elimination

Consider the essential hazard condition when input literals undergo asynchronous transitions across adjacent K-map clusters:


```latex
F_{raw} = A \cdot \overline{B} + B \cdot C
```


During the dynamic transition where $B$ switches from `$1 \to 0$` while $A=1$ and $C=1$, propagation delay through the inverter `$\overline{B}$` introduces a momentary zero-glitch:


```latex
F_{glitch}(t) = 1 \cdot \overline{B(t)} + B(t) \cdot 1
```


To guarantee static-1 hazard immunity compliant with IEEE 1076.1 standards, the consensus term `$A \cdot C$` must bridge the boundary:


```latex
F_{hazard-free} = A \cdot \overline{B} + B \cdot C + A \cdot C
```

## II. Frequency Domain Bode Plot Stability & Phase Margin Derivation

Control loop stability in embedded power management (DC-DC buck converters) and analog front-ends (AFEs) is evaluated through the logarithmic open-loop transfer function $G(s)H(s)$.

The asymptotic magnitude response in decibels is defined as:


```latex
|G(j\omega)H(j\omega)|_{dB} = 20 \log_{10} |G(j\omega)H(j\omega)|
```


And the corresponding phase angle:


```latex
\angle G(j\omega)H(j\omega) = \sum \arctan\left(\frac{\omega}{\omega_{z_i}}\right) - \sum \arctan\left(\frac{\omega}{\omega_{p_k}}\right)
```


### Gain Margin ($GM$) and Phase Margin ($PM$) Criteria

Let `$\omega_{gc}$` denote the gain crossover frequency where the magnitude equals $0 dB$, and `$\omega_{pc}$` denote the phase crossover frequency where the phase equals `$-180^\circ$`:


```latex
|G(j\omega_{gc})H(j\omega_{gc})| = 1 \implies 0 dB
```



```latex
\angle G(j\omega_{pc})H(j\omega_{pc}) = -180^\circ
```


The Phase Margin ($PM$) and Gain Margin ($GM$) are analytically derived as:


```latex
PM = 180^\circ + \angle G(j\omega_{gc})H(j\omega_{gc})
```



```latex
GM = -20 \log_{10} |G(j\omega_{pc})H(j\omega_{pc})|
```


For deterministic stability in automotive radar and aerospace sensor feedback systems, precision instrumentation design rules enforce `$PM \ge 45^\circ$` and `$GM \ge 6 dB$` across operating temperature bands (`$-40^\circC$` to `$+125^\circC$`).

## III. Pipelined Assembly Tracing: 8051 CISC vs. ARM Cortex-M RISC

Embedded firmware engineers must trace low-level register transformations at assembly boundaries.

### 8051 Microcontroller Architecture

The Intel 8051 utilizes a Harvard architecture with an 8-bit accumulator (`ACC`), auxiliary register `B`, program status word (`PSW`), and bank-switched working registers (`R0`–`R7`). A 16-bit Timer 0 auto-reload interrupt sequence executes as follows:

```assembly
; ==========================================================
; Core Microcontroller Track - 8051 Timer 0 ISR (10 kHz)
; ==========================================================
ORG 000BH               ; Timer 0 Interrupt Vector
PUSH PSW                ; Preserve Program Status Word
PUSH ACC                ; Preserve Accumulator
MOV TH0, #0F6H          ; Reload 16-bit High Byte
MOV TL0, #3CH          ; Reload 16-bit Low Byte
CPL P1.0                ; Toggle GPIO Pin P1.0 (5 kHz Square Wave)
POP ACC                 ; Restore Accumulator
POP PSW                 ; Restore PSW flags
RETI                    ; Return from Interrupt
```

### ARM Cortex-M4 Pipelined Execution

Modern 32-bit Cortex-M4 cores leverage a 3-stage fetch-decode-execute pipeline with Thumb-2 instruction set encoding. Fast context stacking automatically pushes registers `R0`–`R3`, `R12`, `LR`, `PC`, and `xPSR` onto the Process Stack Pointer (`PSP`) in exactly 12 clock cycles:

```assembly
// ==========================================================
// ARM Cortex-M4 - Fast Atomic GPIO Toggle in Assembly
// ==========================================================
.syntax unified
.thumb
.global FastGpioToggle

FastGpioToggle:
    LDR     R0, =0x40020018     // Load GPIOA_BSRR address (Bit Set/Reset)
    MOVS    R1, #(1 << 5)       // Pin 5 mask (High)
    STR     R1, [R0]            // Set PA5 High atomically (Zero Dead-Time)
    MOVS    R2, #(1 << 21)      // Pin 5 reset mask (Low)
    STR     R2, [R0]            // Reset PA5 Low atomically
    BX      LR                  // Branch exchange return
```
