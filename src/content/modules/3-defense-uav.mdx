# Defense UAV Telemetry & Frequency-Hopping Spread Spectrum (FHSS)

<div class="ieee-abstract">
  <strong>Abstract</strong>—In hostile electronic warfare scenarios and dense urban environments, unmanned aerial vehicle (UAV) command and non-payload telemetry (CNPC) links are subject to severe adversary jamming, extreme multipath propagation, and vehicle velocity-induced Doppler shifts. This module explores the architecture of an anti-jamming communication node utilizing dual-band Semtech SX1280 (2.4 GHz) and SX1262 (915 MHz) transceivers coupled to an ESP32-S3 embedded controller. By executing pseudo-random frequency hopping (FHSS) at up to 200 hops/second with deterministic FreeRTOS SPI DMA transactions, the link ensures continuous telemetry survival under aggressive wideband and swept-tone interference.

## I. System Architecture & Frequency Hopping Mechanics

The telemetry payload is digitized and packetized into encrypted frames (AES-256-GCM) by the flight controller and dispatched to the RF front-end via dedicated Direct Memory Access (DMA) channels.

The pseudo-random channel hopper selects carrier frequencies based on an authenticated seed shared during the initial pre-flight cryptographical handshake:


```latex
f_k = f_{base} + \left[ LFSR_{32}(k) \pmod N_{channels} \right] \cdot \Delta f_{channel}
```


Where:
- `$f_{base} = 2.402  GHz$`
- `$N_{channels} = 80$` channels spaced at `$\Delta f_{channel} = 1.0  MHz$`
- Dwell time per hop `$\tau_{dwell} = 10  ms$` (yielding 100 hops per second)

```text
+-----------------------+       SPI DMA (32 MHz)       +-----------------------+
|  Flight Computer      | ---------------------------> |  SX1280 Transceiver   |
|  (ESP32-S3 FreeRTOS)  | <--------------------------- |  (2.4 GHz LoRa/FHSS)  |
+-----------------------+           GPIO IRQ           +-----------------------+
            |                                                      |
            +------------ TCXO (32 MHz, ±0.5 PPM) -----------------+
```

## II. The Engineering Trap: Multipath Urban Canyon Doppler Shift

<div class="glass-card p-5 rounded-2xl border border-red-500/40 bg-[#041026]/90 space-y-3 my-6">
  <div class="flex items-center gap-2 text-red-400 font-mono font-bold text-sm tracking-wide">
    <span class="text-base">⚠️</span>
    <span>ENGINEERING TRAP: THE MULTIPATH URBAN CANYON DOPPLER SHIFT CRISIS</span>
  </div>

  <p class="text-xs text-slate-200 leading-relaxed font-sans">
    During low-altitude UAV maneuvers between urban concrete structures (such as dense high-rise urban structures), students often encounter an abrupt, unexplained link drop exceeding <strong>98% packet loss</strong> even when transmitter RSSI is measured at a robust <strong>-68 dBm</strong>.
  </p>

  <div class="p-3 rounded-xl bg-[#020813] border border-red-500/30 text-xs font-mono text-slate-300 space-y-1.5">
    <div class="text-amber-400 font-bold">1. Root Failure Mechanism:</div>
    <div>
      When a UAV travels at velocity $v = 108  km/h$ ($30  m/s$) at 2.4 GHz (`$\lambda = 0.125  m$`), the direct line-of-sight Doppler shift is:
    </div>
    <div class="text-center py-1 text-[#00F0B5]">
      
```latex
\Delta f_D = \frac{v}{\lambda} \cos(\theta) = \frac{30}{0.125} \cdot 1.0 = \pm 240  Hz
```

    </div>
    <div>
      Simultaneously, reflections from opposing building facades arrive with reverse Doppler velocity (`$\cos(\theta) \approx -1$`), generating a destructive Doppler spread `$B_D \approx 480  Hz$`.
    </div>
    <div class="text-amber-400 font-bold pt-1">2. LoRa Demodulator Collapse:</div>
    <div>
      In LoRa Chirp Spread Spectrum (CSS), symbols are demodulated by multiplying the received signal by a conjugate unmodulated base down-chirp. If the carrier frequency offset exceeds <strong>25% of the chirp bin width</strong>:
    </div>
    <div class="text-center py-1 text-red-300">
      
```latex
\Delta f_{threshold} = \frac{Bandwidth}{2^{Spreading Factor + 2}}
```

    </div>
    <div>
      For $SF = 10$ and $BW = 203  kHz$, `$\Delta f_{threshold} \approx 49.5  Hz$`. A $240  Hz$ Doppler shift shifts the FFT peak across <strong>5 discrete bin addresses</strong>, resulting in catastrophic cyclic parity check (CRC) corruption.
    </div>
  </div>

  <div class="p-3 rounded-xl bg-[#00693E]/20 border border-[#00F0B5]/30 text-xs font-mono text-slate-300 space-y-1">
    <div class="text-[#00F0B5] font-bold">✓ Defense UAV Telemetry Mitigation Protocol:</div>
    <ul class="list-disc list-inside space-y-1 text-slate-300">
      <li><strong>TCXO Hardware Mandate:</strong> Discard standard 10 PPM passive crystals; employ a 32 MHz TCXO with `$\le 0.5  PPM$` drift across `$-40^\circC$` to `$+85^\circC$`.</li>
      <li><strong>Automatic Frequency Correction (AFC):</strong> Configure the SX1280 <code>SetLoRaSymbNumTimeout()</code> and enable continuous carrier frequency tracking registers <code>REG_LR_ESTIMATED_FREQ_ERROR</code> to offset the local NCO prior to payload demodulation.</li>
      <li><strong>Adaptive Spreading Factor:</strong> Step down to $SF = 7$ ($BW = 812  kHz$) during high-velocity ingress to expand the bin tolerance window to `$\approx 396  Hz$`.</li>
    </ul>
  </div>
</div>

## III. Wokwi Simulation Topology & Firmware Implementation

The following Arduino C++ / FreeRTOS sketch operates the SX1280 transceiver state machine with pseudo-random frequency hopping and real-time AFC Doppler compensation:

```cpp
/**
 * VoltCore Apex Academia - Module 3: Defense UAV FHSS Telemetry Node
 * Hardware: ESP32-S3 + Semtech SX1280 (2.4 GHz)
 * Target: Autonomous UAV Avionics Test Bench
 */

#include <SPI.h>
#include <WiFi.h>

#define PIN_SX1280_CS    10
#define PIN_SX1280_BUSY  9
#define PIN_SX1280_RST   8
#define PIN_SX1280_DIO1  7

// Pseudo-Random Frequency Hopping Table (80 Channels in 2.4 GHz Band)
const uint32_t HOP_FREQUENCIES_HZ[8] = {
    2402000000, 2415000000, 2428000000, 2441000000,
    2454000000, 2467000000, 2475000000, 2480000000
};

volatile uint8_t currentHopIdx = 0;
hw_timer_t* hopTimer = NULL;
portMUX_TYPE hopMux = portMUX_INITIALIZER_UNLOCKED;

void IRAM_ATTR onHopTimerISR() {
    portENTER_CRITICAL_ISR(&hopMux);
    currentHopIdx = (currentHopIdx + 1) & 0x07;
    // Fast frequency retune command written via direct SPI register
    digitalWrite(PIN_SX1280_CS, LOW);
    SPI.transfer(0x86); // Opcode: SetRfFrequency
    SPI.transfer((HOP_FREQUENCIES_HZ[currentHopIdx] >> 16) & 0xFF);
    SPI.transfer((HOP_FREQUENCIES_HZ[currentHopIdx] >> 8) & 0xFF);
    SPI.transfer(HOP_FREQUENCIES_HZ[currentHopIdx] & 0xFF);
    digitalWrite(PIN_SX1280_CS, HIGH);
    portEXIT_CRITICAL_ISR(&hopMux);
}

void setup() {
    Serial.begin(115200);
    SPI.begin(12, 13, 11, PIN_SX1280_CS); // SCK=12, MISO=13, MOSI=11
    
    pinMode(PIN_SX1280_CS, OUTPUT);
    pinMode(PIN_SX1280_RST, OUTPUT);
    pinMode(PIN_SX1280_BUSY, INPUT);
    pinMode(PIN_SX1280_DIO1, INPUT);

    // Hardware reset pulse
    digitalWrite(PIN_SX1280_RST, LOW); delay(5);
    digitalWrite(PIN_SX1280_RST, HIGH); delay(10);

    Serial.println(F("[UAV FHSS] Initializing SX1280 2.4GHz FHSS Core..."));
    
    // Configure 10ms (100 Hops/Sec) Precision Hardware Timer
    hopTimer = timerBegin(0, 80, true); // 80 MHz / 80 = 1 MHz (1 us per tick)
    timerAttachInterrupt(hopTimer, &onHopTimerISR, true);
    timerAlarmWrite(hopTimer, 10000, true); // 10,000 us = 10 ms dwell
    timerAlarmEnable(hopTimer);

    Serial.println(F("[UAV FHSS] Frequency Hopping Active: 100 Hops/sec, Doppler AFC Armed."));
}

void loop() {
    // Normal telemetry frame transmission executed outside ISR
    vTaskDelay(pdMS_TO_TICKS(100));
}
```
