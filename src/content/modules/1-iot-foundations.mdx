## I. Bare-Metal Register Manipulation vs Abstraction Layers

Direct register operations using dedicated set/clear registers guarantee single-cycle atomic execution without disabling interrupts:

```c
// Atomic GPIO Pin Toggle avoiding Read-Modify-Write Race Hazards
#define GPIO_OUT_W1TS_REG  (*(volatile uint32_t *)(0x3FF44008)) // Write 1 to SET
#define GPIO_OUT_W1TC_REG  (*(volatile uint32_t *)(0x3FF4400C)) // Write 1 to CLEAR

void inline set_pin_high(uint8_t pin) {
    GPIO_OUT_W1TS_REG = (1 << pin); // Atomic hardware set
}

void inline set_pin_low(uint8_t pin) {
    GPIO_OUT_W1TC_REG = (1 << pin); // Atomic hardware clear
}
```

    <p>
      PIR sensors detect differential infrared emissions in the <strong>8 to 14 µm</strong> optical spectrum (human body temperature ≈ 37°C corresponds to peak radiant exitance at λ_peak ≈ 9.35 µm per Wien's Displacement Law). Standard soda-lime window glass has an extinction coefficient that is virtually opaque (≈ 99.8% absorption) to wavelengths above 4.5 µm. Consequently, human movement behind glass is completely invisible to the pyroelectric crystal!
    </p>

    <div class="text-amber-400 font-bold pt-1">2. Acoustic & Thermal Airflow False Triggers:</div>
    <p>
      Air conditioning registers emitting fluctuating thermal plumes produce convection currents across the Fresnel lens. The pyroelectric crystal senses differential temperature gradient dT/dt &gt; 0.05°C/s, generating false positive triggering.
    </p>
